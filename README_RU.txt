Vision Mod — исходники прототипа для Minecraft 1.21.11 Fabric.

ВАЖНО: Это НЕ готовый .jar. Сборка здесь не проверена из-за отсутствия доступа к Maven.
Реализовано: переключение End (с изменяемым биндом в настройках), ON/OFF и попытка FullBright через gamma.
НЕ реализовано: подсветка руд, удаление тумана в воде и лаве.

Сборка: загрузить файлы в репозиторий GitHub и запустить Actions -> Build Vision Mod -> Run workflow.
После успешной сборки скачать артефакт visionmod-jar; для игры использовать jar без -sources.
Если сборка падает, пришлите лог — можно исправить версии зависимостей или изменения API.
